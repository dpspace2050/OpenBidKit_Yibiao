## 发现的既有问题（非本功能引入）

1. **aiService.chat 流式请求无超时**：html 配图源码/正文生成的 AI 请求可静默挂起（两次实测：43 分钟与隔夜），仅靠 Pi Agent watchdog（约 40 分钟）兜底 abort。建议为 chat 请求增加空闲超时与自动重试。
2. dev 模式 OpenXmlHelper 依赖链：`npm run dev` 不产出 helper；csproj 目标 net10 需 .NET 10 SDK；apphost 解析 runtime 只认 `DOTNET_ROOT`（不走 PATH）。**T12 打包（dotnet publish）同样需要 SDK 10 + DOTNET_ROOT**。
3. Electron renderer 出现过一次无日志自动重载（疑似崩溃自恢复），主进程任务不受影响。
4. 保存对话框需激活窗口后 SendKeys ENTER（AppActivate + SendKeys 可靠；裸 SendKeys 不可靠）。
5. 打赏弹窗由 word 导出触发延迟展示，会与业务弹窗叠加干扰自动化（人工使用无碍）。
